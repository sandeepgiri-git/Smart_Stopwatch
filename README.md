# Smart Study Stopwatch ⏱️📚

Smart Study Stopwatch is a productivity-focused Chrome extension designed specifically for learners and developers. It automatically tracks the time you spend on educational websites, helping you stay focused, build study streaks, and analyze your learning habits.

![Smart Study Stopwatch](icon.png) <!-- Note: Replace with actual screenshot path if available -->

## ✨ Features

- **🎯 Smart Tracking:** Only tracks time on whitelisted educational websites (like Udemy, Coursera, LeetCode, MDN).
- **⏸️ Auto-Pause:** Automatically stops tracking if you are idle (no mouse/keyboard movement) for a customizable amount of time.
- **🔥 Gamification & Streaks:** Set a daily study goal. Watch your progress ring fill up in the popup, and build your daily streak to stay motivated!
- **📊 Analytics Dashboard:** A beautiful dark-themed dashboard featuring:
  - A GitHub-style heatmap calendar showing your study activity over the past year.
  - Detailed per-website and per-category breakdowns (e.g., *Video Courses*, *Coding Practice*).
  - Clickable calendar days to see exactly what you studied on specific dates.
- **📂 Website Categorization:** Sites are automatically grouped by category, but you can manually override them in the Settings page.

## 🚀 How to Download and Install

Because this is a custom extension that isn't on the Chrome Web Store yet, you will need to install it locally as an "unpacked extension." Don't worry, it only takes a minute!

### Step 1: Download the Project
1. Scroll to the top of this GitHub repository.
2. Click the green **`<> Code`** button.
3. Click **`Download ZIP`**.
4. Once downloaded, **extract/unzip** the folder to a location on your computer where you won't accidentally delete it (like your Documents folder).

*(Alternatively, if you use Git, you can clone the repository: `git clone https://github.com/sandeepgiri-git/Smart_Stopwatch.git`)*

### Step 2: Open Chrome Extensions Page
1. Open Google Chrome.
2. In the URL bar at the top, type `chrome://extensions/` and hit Enter.
   *(Or click the puzzle piece icon 🧩 in the top right -> **Manage Extensions**).*

### Step 3: Enable Developer Mode
1. In the top right corner of the Extensions page, you will see a toggle switch labeled **Developer mode**.
2. **Turn this switch ON**. (New buttons will appear at the top left of the page).

### Step 4: Load the Extension
1. Click the **Load unpacked** button in the top left.
2. A file browser window will open. Navigate to the folder you extracted in Step 1.
3. **Select the folder** that contains the `manifest.json` file (it should be the main `Smart_Stopwatch` folder) and click **Select Folder**.

### Step 5: Pin it and Start Learning!
1. The extension is now installed! 
2. Click the puzzle piece icon 🧩 in the top right of your Chrome window.
3. Find **Smart Study Stopwatch** in the list and click the **Pin icon** 📌 next to it.
4. Click the newly pinned icon to open the popup, customize your daily goals, add your favorite study sites in Settings, and start tracking!

## 🛠️ Configuration

- **Settings:** Click the ⚙️ button in the popup to manage your whitelisted sites, set your idle timeout (default is 2 minutes), assign categories, and enable your daily goal.
- **Dashboard:** Click the 📊 button to view your long-term analytics and heatmap.

Enjoy building your learning streaks! 🚀
